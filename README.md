## 🔴 Currently Active

### Code-Flow AI — AMD Lablab.ai Hackathon
> **Status: 🟡 In Progress**

**Event:** AMD Hackathon on Lablab.ai
**Host:** AMD Developer Cloud × Lablab.ai
**Scope:** International
**Platform:** Online
**Track:** AI / Agentic Systems

**The Problem:**
Developers working with complex or inherited codebases waste enormous time trying to understand how APIs, databases, and services connect. Manual architecture diagrams go stale the moment code changes.

**Our Solution — Code-Flow AI:**
An autonomous agentic tool that takes raw backend code (FastAPI, Node.js) or database schemas and instantly generates:
- 📊 **Live System Architecture Diagrams** — powered by Mermaid.js
- 🔄 **Automated Flowcharts** — visualising the logic of complex functions
- 🔴 **Security & Debt Overlays** — AI-identified vulnerabilities mapped directly onto the visual graph
- 🌐 **Bilingual Reports** — Security audits generated in both English and Urdu

**Tech Stack:**
| Layer | Technology |
|-------|-----------|
| Backend | FastAPI |
| LLM Reasoning | LangChain / CrewAI + Llama 3 via AMD ROCm |
| Diagram Engine | Mermaid.js |
| Frontend | React — corporate dashboard UI |
| Hardware | AMD Developer Cloud |

**AUREX Team:**
| Sub-Team | Responsibility |
|----------|---------------|
| Engineers (2) | Code parsing & LLM prompt logic |
| Architects (2) | Mermaid.js integration & diagram automation |
| Frontend (2) | React dashboard — side-by-side code and diagram view |
| Operations (2) | Testing, documentation & demo video |

## How We Compete

When AUREX fields a hackathon team, it competes with the same standards it applies to client work — structured, documented, and serious.

- **Every team is cross-functional** — engineers, designers, and strategists
- **Every project is scoped before building begins**
- **Every participation is documented** regardless of outcome
- **Every result is recorded honestly** — wins and losses alike

## Participation Standards

To represent AUREX in a hackathon a member must:

- Be an active cabinet member or current intern in good standing
- Have completed at least 2 weeks of active AUREX work
- Receive approval from the Project Manager and President
- Represent AUREX professionally throughout the event
- Submit a brief project report to the General Secretary within 5 days of completion
